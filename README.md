# Java Learning Path - Exercícios Fundamentais

Este repositório contém uma coletânea de arquivos Java utilizados para praticar os fundamentos da linguagem Java. Cada arquivo aborda um conceito ou conjunto de conceitos importantes para quem está iniciando.

---

## 📚 Conteúdo dos Arquivos

### 🔢 Tipos de Dados e Operadores

- **primitiveTypes.java**  
  Demonstração dos tipos primitivos do Java (int, double, boolean, char, etc).

- **nprimitiveDataTypes.java**  
  Explicação e uso de tipos não primitivos (Strings, arrays, objetos, etc).

- **ImplicitDataTypeConversion.java**  
  Conversão automática entre tipos (ex: int → double).

- **ExplicitDataTypeConversion.java**  
  Casting manual de tipos (ex: double → int).

- **ArithmeticDemo.java**  
  Demonstra operações aritméticas básicas.

- **UnaryDemo.java**  
  Mostra operadores unários (++ / -- / + / -).

- **PrePostDemo.java**  
  Demonstra a diferença entre pré-incremento e pós-incremento.

- **LogicalOperator.java**  
  Demonstração dos operadores lógicos: `&&`, `||`, `!`.

- **ComparisonOperator.java**  
  Mostra os operadores de comparação: `==`, `!=`, `<`, `>`, etc.

---

### 📋 Estruturas de Dados

- **ArrayDemo.java**  
  Introdução aos arrays em Java.

- **CollectionsExample.java**  
  Demonstração das coleções `List` e `Set` com `ArrayList` e `HashSet`.

---

### 🚗 Programação Orientada a Objetos (POO)

- **Garagem.java**  
  Exemplo de criação e uso de objetos com uma classe `Carro`. Mostra atributos, métodos e a instância de múltiplos objetos.

---

### 🧪 Extras

- **HelloWord.java**  
  Primeiro programa Java: impressão de "Hello World" no console.

---
